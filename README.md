# VAMP4 Car Racing

A mobile-friendly arcade racing game built with plain HTML, CSS and JavaScript. No external libraries or paid assets are required.

## Run locally
1. Extract this folder.
2. Open `index.html` in Chrome, Edge or Firefox.
3. Press **START RACING**. Use the arrow keys / A and D, or the on-screen steering buttons.

## Upload to GitHub
1. Create a new **public** repository named `vamp4-car-racing`.
2. Choose **Add file → Upload files**.
3. Upload `index.html`, `style.css`, `game.js`, `manifest.json`, and `README.md`.
4. Select **Commit changes**.

## Publish as a website with GitHub Pages
1. Open repository **Settings → Pages**.
2. Under Build and deployment, choose **Deploy from a branch**.
3. Select branch `main`, folder `/ (root)`, then **Save**.
4. Wait for the Pages URL to appear. Open it on a phone to test.

## Important: Google Play Store
This folder is a web game, not an Android app bundle. Google Play normally requires a signed Android App Bundle (`.aab`) for a new app. You must package the game in an Android project (for example, with Capacitor), build and test the signed AAB, complete Play Console app content/data safety declarations, and meet current testing and policy requirements. A GitHub ZIP or HTML file cannot be uploaded directly as a Play Store app. No tool can guarantee approval or zero errors; test on real Android devices before submission.

## Before release
- Replace the VAMP4 branding only if you own or have permission to use it.
- Add your own original app icon and store screenshots.
- Test controls, performance, offline behavior, and different screen sizes.
- Add a privacy policy if your final app collects or shares user data.
